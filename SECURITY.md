# Security

Please report vulnerabilities privately through GitHub: _Security → Report a vulnerability_ in this
repository. Don't open a public issue. You'll get an answer within a few days.

Problems in the API or the model belong to
[blog-backend](https://github.com/E-L-R/blog-backend/security) and
[blog-tldr-model](https://github.com/E-L-R/blog-tldr-model/security).
